# CreditGuard AI 评测说明

## 数据与范围

评测数据全部为合成案件，覆盖正常路径、规则边界、材料矛盾、缺件/坏文件、工具失败和恢复场景。

- 20 个离线评测案件；
- 15 类标准授信事实字段；
- 10 条确定性合规规则；
- 正常、高风险和 RM 手工上传三条浏览器路径。

## 已验证结果

- 25 项后端测试通过；
- 前端类型检查、组件测试和构建通过；
- OpenAPI 生成的 TypeScript 类型无漂移；
- Windows Chromium 浏览器路径通过；
- 安全扫描未发现密钥、PII、本机路径或原始外部响应。

## 模型与可复现性

生成模型配置为 `qwen3.6-flash`，每个 Run 记录请求模型版本。默认本地运行和普通 CI 使用确定性 Mock，不自动访问外部模型服务；真实模型调用必须显式启用并通过环境变量提供凭据。

评测输出包含案件结果、规则结果、证据引用、工作流状态、错误分类和成本统计，便于在相同夹具上重复执行。

## 质量边界

评测用于验证事实、规则、证据、工作流和安全边界，不代表真实银行生产环境的授信决策能力。系统不会自动批准授信、修改额度或发起放款。
