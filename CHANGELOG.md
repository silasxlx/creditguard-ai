# Changelog

## [0.1.0] - Initial public release

- Added controlled normal and high-risk synthetic demo scenarios.
- Added RM/Reviewer Vue workbench with fact, rule, risk and report pages.
- Added OpenAPI-generated TypeScript contract and Playwright browser tests.
- Added architecture, demo, acceptance, security and contribution documentation.
- Added Windows one-command startup with a project-root Worker.

This release is local-only and is not a production lending decision service. It uses synthetic data and provides AI-assisted review only.
